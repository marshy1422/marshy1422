# 🚀 Quick Start: Building Your App on Rork.com

## ⚠️ Important First

**Your code is Flutter, but Rork uses React Native.**

This means you'll describe your app to Rork's AI instead of uploading code.

---

## 📝 3 Steps to Build on Rork

### Step 1: Go to Rork.com
Visit: https://rork.com (or https://rork.app)

**Sign up options:**
- Free trial available
- Paid plans: $20-200/month depending on features

### Step 2: Start New Project
Click **"Create New App"** or **"New Project"**

### Step 3: Copy & Paste Description
Open the file: **`RORK_APP_DESCRIPTION.txt`**

Then:
1. Copy ALL the text from that file
2. Paste it into Rork's description box
3. Click **"Generate"** or **"Build App"**

**Rork's AI will build your app in minutes!**

---

## 🎨 What Rork Will Create

Based on the description, Rork will generate:

✅ Main screen with Viking pet (Bjorn)
✅ Pet stats (Health, Happiness, XP)
✅ 4 activity cards (AI Chat, Mood, Journal, CBT)
✅ Feed & Play buttons
✅ Progress bars
✅ Evolution system
✅ Dark theme with orange accents

---

## ✏️ Refining Your App in Rork

After Rork generates the initial app, you can chat with it:

### Example Refinements:

**"Make the pet avatar bigger"**
**"Change the orange color to blue"**
**"Add a daily streak counter"**
**"Make the cards have more shadow"**
**"Add a settings screen"**

Rork's AI will update the app based on your feedback!

---

## 🔍 Preview & Test

Rork provides:
- **Live preview** - See your app in browser
- **Mobile simulator** - Test on phone mockup
- **QR code** - Test on your actual phone

---

## 📱 Deploy to App Stores

Once satisfied:

1. Click **"Export"** or **"Deploy"**
2. Choose platform:
   - iOS App Store
   - Google Play Store
   - Both
3. Follow Rork's deployment wizard
4. Rork handles the build and submission process

---

## 💰 Pricing Reminder

- **Free tier**: Limited features, good for testing
- **Basic** (~$20/mo): Basic features
- **Pro** (~$100/mo): Advanced features
- **Enterprise** (~$200/mo): Full features + support

Check Rork.com for current pricing.

## 🆚 Alternative: FlutterFlow (Keeps Your Flutter Code)

**Don't want to recreate your app?**

Use **FlutterFlow** instead - it accepts Flutter code directly!

1. Go to https://flutterflow.io
2. Create new project
3. Import from files
4. Upload your `lib/` folder
5. Build & deploy

**Pros:**
- ✅ Keeps your exact code
- ✅ All fixes preserved
- ✅ Visual editor

**Pricing:** Similar to Rork ($30+/month)
